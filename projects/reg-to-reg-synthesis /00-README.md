# REG-to-REG Synthesis & Timing Analysis

## Project Overview

Hands-on RTL synthesis and timing analysis project focused on a REG-to-REG design flow using Synopsys Design Compiler.

## Tool

* Synopsys Design Compiler

## Objective

Convert the RTL design into an optimized gate-level netlist while applying timing constraints and analyzing synthesis quality.

## Design Flow

**Library Setup → RTL Analysis → Elaboration → Compilation → Timing Constraints → Timing Analysis → QoR Analysis**

## Key Areas

* RTL analysis and elaboration
* Technology library setup
* Logic synthesis and optimization
* Clock definition
* Input and output delay constraints
* Clock uncertainty
* Path grouping
* Timing analysis
* QoR analysis
