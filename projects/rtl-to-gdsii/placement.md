# Placement

## Tool

Cadence Innovus

## Objective

Place and optimize standard cells within the defined floorplan while analyzing placement density, congestion, timing, and design-rule constraints.

## Design Information

* Technology: 28nm
* Core utilization: 79.7%

## Key Results

| Metric                     |    Result |
| -------------------------- | --------: |
| Reg-to-Reg WNS             | -0.064 ns |
| Reg-to-Reg TNS             |  -0.10 ns |
| Reg-to-Reg Violating Paths |         3 |
| In-to-Reg WNS              |  1.863 ns |
| Reg-to-Out WNS             |  2.959 ns |
| In-to-Out WNS              |  4.758 ns |
| Max Transition             |    -4.451 |
| Max Capacitance            |   -34.205 |

## Work Performed

* Standard-cell placement
* Placement legalization
* Density analysis
* Congestion analysis
* Timing optimization
* Buffer and inverter optimization

## Outcome

The standard cells were placed and optimized for the defined floorplan, preparing the design for Clock Tree Synthesis.
