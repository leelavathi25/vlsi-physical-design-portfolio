# RTL-to-GDSII Physical Design Project

## Project Overview

Hands-on VLSI Physical Design project completed as part of my Physical Design training.

The project involved the ASIC RTL-to-GDSII implementation flow, including synthesis, floorplanning, placement, clock tree synthesis, routing, timing analysis, and physical verification.

## Technology

- 28nm ASIC
  
## Design Flow

RTL → Synthesis → Floorplanning → Placement → CTS → Routing → Timing Analysis → Physical Verification

## Tools

- Cadence Genus
- Cadence Innovus
- Synopsys Design Compiler
- Synopsys ICC2

## Key Areas

- Floorplanning
- Power Planning
- Placement
- Clock Tree Synthesis (CTS)
- Routing
- Static Timing Analysis (STA)
- Timing Optimization
- DRC / LVS / ERC
