# Routing

## Tool

Cadence Innovus

## Objective

Route the placed design by connecting standard cells, macros, and clock networks while analyzing routing quality and design-rule violations.

## Design Information

* Technology: 28nm
* Core utilization: 79%

## Key Results

| Metric             | Result |
| ------------------ | -----: |
| DRC Violations     |    375 |
| Shorts             |      0 |
| Opens              |   1000 |
| Antenna Violations |     19 |

## Work Performed

* Global routing
* Detailed routing
* Routing congestion analysis
* DRC analysis
* Open and short analysis
* Antenna violation analysis
* Critical-net routing optimization

## Outcome

The design was routed and routing-related violations were analyzed as part of the physical implementation flow before post-route optimization.
