# Routing

## Tool

Synopsys ICC2

## Objective

Perform physical routing of the `Tile` design and analyze routing quality through DRC, shorts, opens, and antenna checks.

## Routing Metrics

| Metric | Value |
|---|---:|
| Core Utilization | 79.93% |
| DRC Violations | 25 |
| Shorts | 48 |
| Opens | 79 |
| Antenna Violations | 0 |

## Routing Analysis

The routing stage included analysis of:

- Design rule violations
- Metal shorts
- Open connections
- Antenna violations
- Post-routing physical quality

Initial routing produced DRC, short, and open violations that were subsequently addressed during post-route implementation and debugging.

## Outcome

The routing stage was completed and the design progressed to post-route analysis and signoff. The final post-route stage achieved zero DRC violations, zero shorts, and zero opens.
