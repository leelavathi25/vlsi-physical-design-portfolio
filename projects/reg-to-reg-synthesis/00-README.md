# REG-to-REG Synthesis & Timing Analysis

## Project Overview

Hands-on RTL synthesis and timing analysis project focused on a REG-to-REG design flow using Synopsys Design Compiler.

The project covers technology library setup, RTL analysis and elaboration, logic synthesis, timing constraint development, timing analysis, and Quality of Results (QoR) analysis.

## Tool

- Synopsys Design Compiler

## Design Flow

**Library Setup → RTL Analysis → Elaboration → Compilation → Timing Constraints → Timing Analysis → QoR Analysis**

## Key Areas

- RTL synthesis and optimization
- Timing constraints
- Static timing analysis
- QoR analysis
- Design and timing checks
